Cómo usar esta comparación
  1. Elegí las versiones izquierda y derecha y el capítulo que querés revisar.
  2. Usá PDF para leer ecuaciones y figuras. Cada panel se desplaza por separado.
  3. Elegí Ver diferencias para abrir el código con cambios resaltados: verde agregado, rojo retirado y amarillo modificado.
  4. Usá Código .tex para leer y copiar el texto completo. Descargar .tex guarda una copia del capítulo seleccionado.
  5. Para redactar, duplicá una carpeta de fuentes/ como carpeta de trabajo y editá sus capítulos en TeXstudio. Abrí revision.tex como documento principal; contiene sólo 3, 5 y 6. Consultá README.md para compilar.

Los cambios se comparan como texto LaTeX; no son una evaluación de la física ni un diff sobre el PDF. No se aceptó ni fusionó ninguna versión automáticamente. El visor no guarda ediciones. Las notas GAP están en inglés y tienen otra estructura: contrastalas por tema, usando la guía de abajo.
