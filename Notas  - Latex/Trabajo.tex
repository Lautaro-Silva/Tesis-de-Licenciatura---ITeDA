\subsubsection*{Refinamiento del Análisis: Barras de Error}

El otro punto que faltaba en mis plots de asimetría (\lstinline|S/<S>| vs \lstinline|phi_plane|) eran las \textbf{barras de error}.

\begin{itemize}
	\item \textbf{Por qué son importantes:} Sin barras de error, es imposible saber si la campana (o la falta de ella) es una señal física real o simplemente una fluctuación estadística (ruido) porque un bin tiene pocos puntos.
	
	\item \textbf{Metodología (SEM):} Para agregar esto, cambié la forma en que calculo los bines. En lugar de usar \lstinline|np.histogram| dos veces (uno para la suma y otro para el conteo), ahora uso la función \lstinline|pandas.groupby().agg()|.
	
	\item Esto me permite calcular, para cada bin de \lstinline|phi_plane|, tres cosas de una sola vez:
	\begin{itemize}
		\item \lstinline|'mean'|: La densidad promedio de muones (mi $S$).
		\item \lstinline|'count'|: El número de módulos ($N$) en ese bin.
		\item \lstinline|'std'|: La desviación estándar ($\sigma$) de los muones en ese bin.
	\end{itemize}
	
	\item \textbf{El Error Estadístico:} Con esto, calculo el **Error Estándar de la Media (SEM)** para cada bin:
	$$ SEM = \frac{\sigma}{\sqrt{N}} $$
	
	\item \textbf{Resultado Final:} Ahora ploteo la media normalizada (\lstinline|S/<S>|) como el punto, y el \lstinline|SEM| normalizado (\lstinline|SEM / <S>|) como la barra de error (\lstinline|plt.errorbar|). Esto me permite ver con confianza estadística si la asimetría es real.
\end{itemize}

		\item Si da $A_1 = 0.1 \pm 0.02$, es una señal real que estaba escondida en el ruido.

Al analizar el set de Helio de mayor energía, la asimetría \textbf{sí aparece}:
\begin{itemize}
	\item Para lluvias poco inclinadas ($\theta < 39^\circ$), la amplitud $A_1$ sigue siendo nula ($\approx 0 \pm 0.001$).
	\item Para lluvias inclinadas ($\theta > 39^\circ$), la señal es estadísticamente significativa. En el bin de $\theta \approx 50^\circ$ ($[46.2^\circ, 53.8^\circ]$), la amplitud es:
	\begin{itemize}
		\item \textbf{UMD:} $A_1 = 0.0052 \pm 0.0016$ (una detección de \textbf{3.2$\sigma$})

	\item \textbf{Conclusión:} Esto confirma que la asimetría \textbf{depende fuertemente de la energía} (y del ángulo $\theta$), tal como predecían los papers. No era un error de mi código, sino un resultado físico.
